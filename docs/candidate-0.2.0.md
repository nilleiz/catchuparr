# Superseded 0.2.0 candidate

The 0.2.0 candidate was never published. Its separate UUID selection and source
rule interface have been superseded by the unified 0.2.1 YAML filter engine.

Use the [0.2.1 candidate guide](candidate-0.2.1.md). There is no configuration
migration; previous settings and snapshots do not activate recording.
