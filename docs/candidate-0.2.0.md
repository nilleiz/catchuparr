# Superseded 0.2.0 candidate

The 0.2.0 candidate was never published. Its separate UUID selection and source
rule interface have been superseded by the unified 0.2.1 YAML filter engine.

The YAML filter engine that replaced this interface was incorporated into the
later 0.2.1 and 0.3.1 candidates, then released in 0.4.0. See the
[0.4.0 release guide](candidate-0.4.0.md) for the current baseline. There was
no separate 0.2.0 release; previous settings and snapshots do not activate
recording. Historical server-side evidence remains in
[validation status](validation.md).
