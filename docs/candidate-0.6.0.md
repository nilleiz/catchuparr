# Catchuparr 0.6.0 candidate history

Version 0.6.0 introduced optional reuse of compatible native live connections.
Its pinned Dispatcharr 0.32.0 synthetic AIO acceptance passed; required GitHub
CI and publication were still pending at that checkpoint. The 0.6.0 candidate
is superseded by the global settings and migration changes in
[candidate 0.6.1](candidate-0.6.1.md).

The native acceptance covered existing-viewer borrowing, source assignment
limits, viewer preservation, cleanup, source switching, Apply and Stop
revocation, restart recovery and acknowledgement retries. This synthetic
server-side evidence does not establish real-player acceptance.
